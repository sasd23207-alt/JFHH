# MASAR Development Studio

A clean, cloud-based development workspace for MASAR projects.

## Start here

1. Open this repository in GitHub Codespaces.
2. Open the integrated terminal: **Terminal → New Terminal**.
3. Check Python: `python --version`.
4. Run the starter program:

```bash
python main.py
```

5. Run the tests:

```bash
python -m unittest discover -s tests -v
```

## Workspace

- `main.py` — first Python program.
- `tests/` — automated tests.
- `docs/START_HERE.md` — beginner-friendly first steps.
- `.vscode/settings.json` — dark editor theme and useful defaults.

## Important

This workspace is separate from the MASAR business repositories. Do not copy secrets, passwords, API keys, or customer data into GitHub. Add project-specific dependencies only when a project needs them.
